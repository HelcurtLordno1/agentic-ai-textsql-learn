## Pause/resume

```bash
uv run --frozen --extra ui --group dev python -m scripts.tmux_benchmarks pause --name v5-intent600-20261016
uv run --frozen --extra ui --group dev python -m scripts.tmux_benchmarks status --name v5-intent600-20261016
# Đợi PAUSED sạch, checkpoint + unload + cooldown hoàn tất, rồi:
uv run --frozen --extra ui --group dev python -m scripts.tmux_benchmarks resume --name v5-intent600-20261016
tmux attach -t v5-intent600-20261016
```

Sau shutdown bất ngờ: áp lại cap600MHz, kiểm tra không còn stale jobs và idle an toàn;
resume một recovery pilot rồi đợi PAUSED sạch trước khi resume bình thường:

```bash
uv run --frozen --extra ui --group dev python -m scripts.tmux_benchmarks resume --name v5-intent600-20261016 --recovery-pilot
```

cần xử lý nguyên nhân thực và calibration mới. Không tăng ngưỡng70W. `COMPLETE`
chỉ khi đủ IDs cả hai report và backend cleanup đạt. Reports/predictions giữ ignored:
